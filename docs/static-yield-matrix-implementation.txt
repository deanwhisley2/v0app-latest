================================================================================
SESSION REGISTRATION FLOW
================================================================================

Admin registers session (no manual yield input):
  1. Admin sets start time + morning/evening slot
  2. registerTradeSession() calls resolveMatrixYieldPercent(start, slot)
  3. Sets trade_sessions.max_yield_percent automatically
  4. yield_distribution_mode = LINEAR_TIME_WEIGHTED

File: lib/server/trade-sessions.ts

================================================================================
USER JOIN FLOW (unchanged logic, matrix-sourced base %)
================================================================================

activateTradeSessionBot() in nexus-bot-session-service.ts:
  1. Reads tradeSession.maxYieldPercent from DB (matrix-assigned at register)
  2. joinTradeSessionWithYieldEngine() calculates time-weighted yield
  3. Late join: earnedPercent = participationRatio × maxYieldPercent
  4. Stores expected_profit_usd at join (immutable for settlement)

Example: 0.6% max, 8h session, join 3h late → (5/8) × 0.6 = 0.375%

================================================================================
SETTLEMENT FLOW (simplified)
================================================================================

settleTradeSessionParticipation() in lib/server/trade-session-settlement.ts:
  1. Load stored yield participant row
  2. Pay expected_profit_usd (no reserve debit, no slot ledger)
  3. Mark participant settled

Auto-bots (24h/7d/14d/30d): capital stays locked until session close;
only net profit released to Pocket on settlement (existing ledger path).
